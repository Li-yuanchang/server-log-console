# 设置与连接管理拆分方案

更新时间：`2026-07-03`

## 背景

原 `连接设置` 弹窗同时承载导入、服务器清单、手动维护、当前连接凭证、堡垒机/JumpServer 路由等能力。功能并非缺失，但信息架构混杂，用户容易把它理解为“只设置账号密码”，也不容易发现服务器删除、编辑、导入入口。

参考 FinalShell 的成熟结构后，本项目采用“借鉴管理模式，不照搬视觉与全部功能”的方案：

- `偏好设置` 管软件体验和默认行为。
- `连接管理` 管服务器连接清单、导入、凭证和路由。

## 功能边界

### 偏好设置

用于调整应用体验，不直接修改服务器连接数据。

第一阶段已落地：

- 外观：主题切换、背景方案、界面密度、动效策略，均写入本地偏好并即时生效。
- 布局：活动记录高度展示，状态面板自动刷新开关。
- 日志预览：异常高亮开关、切片大小策略。
- 字体：日志字号通过 CSS 变量即时作用到日志预览；终端字号通过 xterm 参数更新并重新 fit。
- 浮层：路径历史、传输记录显示开关。
- 终端：字号已落地；字体族和复制粘贴规则继续单独拆分。
- 高级：本地服务状态、导入路径、缓存与开发工具说明。

### 连接管理

用于维护服务器连接数据。

第一阶段已落地：

- 导入：FinalShell / Xshell 导入入口。
- 连接清单：展示所有服务器，区分内置、手动、导入来源。
- 手动连接：新增/编辑手动服务器。
- 删除规则：手动服务器和导入服务器可删除；内置演示服务器不删除。
- 当前服务器：凭证、入口账号、JumpServer 资产搜索和路由配置。

## 命名调整

- `连接设置` 改为 `设置中心` 或 `连接管理`，避免误解为仅账号密码设置。
- `服务器台账` 改为 `连接清单`。
- `手动维护` 改为 `手动连接`。
- `当前连接` 改为 `当前服务器`。
- `导入与概览` 改为 `导入来源`。
