## 1. 归档目的

本文档用于沉淀 `server-log-console` 截至 `2026-04-07` 的真实建设状态，明确以下信息：

- 哪些功能已经做完

这份文档的目标不是“报喜”，而是给后续继续开发、验收、回溯提供一个可信的阶段快照。

## 2. 项目目标回顾

当前项目目标已经比较明确，不再是一个普通后台页，而是一个更贴近 FinalShell 使用习惯的中文日志工作台：

- 支持导入 FinalShell 连接，也支持手动维护服务器
- 通过 SSH 连接 Linux 服务器读取任意日志文件
- 支持目录浏览、日志文件选择、历史检索、实时日志
- 支持大日志切片阅读、结果下载、实时片段下载
- 同时支持本地网页模式和 Chrome 插件模式
- 重点覆盖测试与开发环境，生产环境不做系统内部主动自动连接

## 3. 总体完成度

按当前范围评估，项目整体完成度约为 `87%`。

这个 `87%` 的含义是：

- 主链路已经打通，能真实连接服务器、选目录、开日志、查日志、看实时、下载片段
- 搜索结果已经支持点击后回跳到原日志上下文
- 实时跟随已经补上前端自动重连链路
- 堡垒机二跳已经接入基础版，但仍依赖真实可用的堡垒机凭证
- 工程已经可构建、可运行、可验证，不是静态原型
- 但 UI 还没有完全收敛到用户预期的 FinalShell 工具化形态
- 大日志阅读体验、插件交付细节、自动化验证体系仍然不够成熟

## 8. 过程中遇到的主要问题与处理情况

### 8.1 页面空白过多，布局像后台表单页

问题：

- 左右面板与工作区没有严格锁在视口中
- 内容按自身高度撑开
- 空目录时直接退化成整页提示

处理：

- 统一使用 `minmax(0, 1fr)` 约束容器
- 明确每个滚动区域的边界
- 空目录也保持左右结构
- 工作区改为视口内单屏布局

结果：

- 大面积空白问题已明显收敛
- 但视觉紧凑度仍需继续优化

### 8.2 UI 太散，按钮和结果离得远

问题：

- 早期设计中操作、状态、结果分散
- 用户选完服务和文件后，不知道下一步干什么
- 页面学习成本偏高

处理：

- 合并日志窗口，改为上方工具条切换模式
- 折叠低频配置项
- 把高频操作向工具条和近旁区域收敛

结果：

- 主链路可理解性提升
- 但仍未完全达到“无需学习即可上手”的标准

### 8.3 远端日志搜索最初使用 Python 方案，引发兼容性问题

问题：

- 初期部分远端读取/解析逻辑依赖 Python
- 在真实环境中出现过 Python 语法兼容问题
- 用户对“服务器上跑 Python 脚本”方案接受度很低

处理：

- 历史搜索主链路已经改为优先使用 `awk`、`grep`、`tail` 等服务器常见命令
- 避免把普通日志搜索强绑定到 Python 运行环境
- 继续保留少量 Python 能力用于目录浏览和切片读取

结果：

- 远端日志链路已经完成去 Python 化
- 当前网关源码中的日志相关远端执行已统一到 shell 工具链：
  - `awk`
  - `grep`
  - `tail`
  - `head`
  - `find`
  - `wc`
  - `stat`
  - `base64`

### 8.4 中文日志内容读取出现编码问题

问题：

- 远程执行过程中读取中文日志时，出现编码异常

处理：

- 远端执行前显式设置：
  - `PYTHONIOENCODING=UTF-8`
  - `LANG=C.UTF-8`
  - `LC_ALL=C.UTF-8`

结果：

- 中文日志内容读取已恢复正常

### 8.5 导入后服务器和凭证刷新丢失

问题：

- 早期导入结果只保存在内存态
- 页面刷新或重启后状态丢失

处理：

- 增加本地配置持久化
- 保存服务器列表、凭证、最近导入信息、最近目录信息

结果：

- 刷新后恢复能力已具备

### 8.6 目录记忆路径容易落到错误位置

问题：

- 本地记忆可能保存了误操作后的空目录
- 刷新后自动打开空路径，用户会误以为功能异常

处理：

- 调整目录记忆策略
- 非根目录且无内容时，不轻易覆盖为默认记忆路径

结果：

- 自动恢复目录更稳定

### 8.7 图标和选中态观感差

问题：

- 早期使用字符按钮和大面积选中底色
- 当前文件态不清晰，视觉比较粗糙

处理：

- 替换为线性 SVG 图标
- 当前文件改为“图标高亮 + 弱化背景”
- 未打开文件图标半透明

结果：

- 基础观感已有改善
- 仍需继续完善图标统一性和工具条成熟度

### 8.8 快捷键与翻页交互缺失

问题：

- 大日志切片能力虽然存在，但缺少高效操作方式

处理：

- 已接入：
  - `Ctrl/Cmd + F`
  - `Ctrl/Cmd + L`
  - `PageUp`
  - `PageDown`
  - `Esc`
- 已做真实运行态验证

结果：

- 基础快捷键已经可用
- 但“滚轮自然翻页”“命中后快速跳转”等体验还未补齐
