# Data Model

## 1. Server Summary

This is the central cross-layer model shared by gateway and extension.

| Field | Type | Description |
|---|---|---|
| `id` | `string` | Internal unique id |
| `name` | `string` | Display name |
| `host` | `string` | SSH host |
| `port` | `number` | SSH port |
| `username` | `string` | SSH username |
| `basePath` | `string` | Suggested log root |
| `profile` | `LogProfile` | Log family hint |
| `tags` | `string[]` | UI and filtering tags |
| `source` | `manual \| finalshell` | Origin of the entry |
| `groupPath` | `string[]` | Imported FinalShell folder hierarchy |
| `authType` | `password \| privateKey \| unknown` | Known auth mode |
| `hasStoredSecret` | `boolean` | Whether FinalShell config contains a secret field |

## 2. Search Request

| Field | Type | Description |
|---|---|---|
| `serverId` | `string` | Target server |
| `filePath` | `string` | Target log file |
| `keyword` | `string?` | Search keyword |
| `date` | `string?` | Date filter |
| `contextLines` | `number?` | Context around matches |
| `useRegex` | `boolean?` | Regex mode |
| `liveMode` | `boolean?` | Reserved for future unified flow |

## 3. Search Response

| Field | Type | Description |
|---|---|---|
| `commandPreview` | `string` | Built remote command |
| `truncated` | `boolean` | Whether payload is large |
| `matches` | `LogSearchMatch[]` | Parsed line-oriented matches |
| `rawOutput` | `string` | Full returned output |

## 4. FinalShell Raw Model

Imported from local JSON files.

### Folder file

Important fields:

- `id`
- `name`
- `parent_id`

### Connection file

Important fields:

- `id`
- `name`
- `host`
- `port`
- `user_name`
- `parent_id`
- `authentication_type`
- `password`

## 5. Runtime credential model

Credentials are not stored in the extension and are currently resolved from process environment.

`SERVER_LOG_CREDENTIALS_JSON` shape:

```json
{
  "server-id": {
    "username": "root",
    "password": "secret"
  }
}
```

## 6. Persistence status

Current phase keeps imported servers in memory only. A future phase can persist:

- imported server snapshots
- user overrides for base path and profile
- audit records
- recent search history
