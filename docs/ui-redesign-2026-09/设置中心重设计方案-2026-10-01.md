# 设置中心重设计方案 · 主题系统（2026-10-01）

> 配套原型：[设置中心重设计原型-2026-10-01.html](./设置中心重设计原型-2026-10-01.html)（自包含，浏览器直接打开；主题卡 / 强调色 / 终端配色 / 状态色均可点击，整个舞台实时换肤；支持 `#t1:obsidian` 式深链直接以指定主题打开某屏）。

## 1. 背景与问题

当前主题设置（commit fd48b64 后）的实际能力：

- 「主题」只有 **现代 / 经典** 两档，且经典处于退役态；
- 「背景方案」4 张缩略卡（默认/雾面/纸感/自定义）承担了本该由主题体系承担的职责；
- **没有暗色模式**（全库无 `prefers-color-scheme`/`data-theme`，暗色仅作为终端/预览的常量 `--shell` 存在）；
- **没有多主题、没有强调色自定义、没有终端配色**；
- 偏好页外观节是「背景方案 + 图片滑杆 + 字体表 + 水印」的平铺，设置项之间的层级关系（全局色 → 背景 → 字体）没有表达出来。

原型 S14 决策条里「暗色模式/跟随系统列入未来计划」——本轮把这块从「未来计划」提为本轮交付。

## 3. 主题体系设计

### 3.1 数据模型

主题 = 元数据对象（TS 常量，驱动画廊与缩略卡）+ token 组（应用到 DOM 的 CSS 变量）：

```ts
interface ThemeMeta {
  id: string;            // "porcelain" | "mist" | ...
  name: string;          // 显示名
  tone: "light" | "dark";
  desc: string;
  swatches: [string, string, string, string]; // [bg, panel, accent, ink] 缩略卡 4 色
  vars: {                // 与现有 token 一一对应，见 style-architecture.md
    bg, panel, panelMuted, ink, inkSoft, inkMuted, line, lineStrong,
    accent, shell, shellInk,
  };
}
```

实现要点：主题静态层仍走 class（`.theme-modern.ui-theme-<id>`）或按 id 查表注入，**组件层只消费既有 token，不感知主题存在**——这是 patchmate「换主题只改 token 不改页面 CSS」的原则，也是本仓库 §10.4 颜色 token-only 约束的自然结果。

### 3.2 内置主题（定稿：4 色彩族 × 浅/深成对 = 8 套）

关键设计：**主题按「色彩个性（族）」组织，每族各有浅色 / 深色变体**。`toneMode=跟随系统` 时在**同族内**浅↔深切换——用户选了「暖调」，白天是暖砂、夜里自动变暖深，色彩个性不丢。

> **色值来源（定稿）**：用户在「主题选款-本系统风格」中确认的 8 套，遵循本系统 DNA（THEME-SPEC / vercel-design / cal-design）：**灰阶骨架 + 单一克制强调色，颜色只做功能不做装饰**。此前的 tweakcn 预设映射版（素白/薄暮/陈纸等）被否决已废弃——教训：外来的"整套染色"预设与本系统的 Vercel Geist 单色基因冲突。

| 族 | 浅色 | 深色 | accent（浅/深） | 说明 |
|---|---|---|---|---|
| 中性 | `geist` 晨白 | `carbon` 碳黑 | `#0070f3` / `#0070f3` | Vercel 本尊：近白/近黑画布 + Vercel 蓝，**默认** |
| 冷调 | `steel` 钢青 | `slate` 深钢 | `#2563eb` / `#60a5fa` | 冷灰蓝 / 深蓝灰，工程感 |
| 暖调 | `sand` 暖砂 | `espresso` 暖深 | `#9a6a1a` / `#d97706` | 暖灰米调 / 暖褐，克制琥珀 |
| 无彩 | `cal` 纯白 | `ink` 墨 | `#1a1a1a` / `#fafafa` | Cal 式零彩色，黑即强调 |

每套主题的数据结构（见原型 `THEMES` 常量）：

```ts
{ id, name, fam, tone, desc,
  v:   { bg, panel, muted, ink, soft, mut, line, lineS, accent, shell, shellInk }, // token 组
  sem: { green, red, amber }   // 该主题专属语义色——深色主题必须单独给值
}
```

**所有取值已过对比度闸门**：正文 `ink/panel ≥ 9`、次要 `soft/panel ≥ 4.5`、辅助 `mut/panel ≥ 3.3`、主按钮文字 `onAcc ≥ 4.5`、分隔线 `line/panel ≥ 1.12`（8/8 通过，脚本复验）。**强调色随主题走**，不再作为一级设置；如需覆盖，入口在「高级 · 自定义主题」（`contrast()` 比较法派生 on-accent，禁用亮度阈值）。

**主题的"图形语言"取舍（重要经验）**：早期版本曾给每套主题配装饰性纹理图案（方格 / 点阵 / 波纹等）铺在卡片和工作区上，结果观感像"壁纸/屏保"，显得廉价且干扰阅读。调研 shadcn / Vercel Geist / Tailwind / Radix / tweakcn 后确认：**一流工具类产品几乎不用装饰图案，靠克制的配色 + 严格间距取胜**。因此最终方案**去掉所有装饰纹理**，主题缩略图 = 真实迷你界面缩略（用主题真实 token 上色的顶栏/侧栏/日志行/按钮），工作区底衬仅用**极淡的 accent 径向光晕**（`radial-gradient` + `color-mix`，透明度 5–11%）营造色温，不产生噪点。

### 3.2.1 背景层（独立于主题的一层，8 种）

背景与主题解耦，作用于工作区底层。**非纯色背景下面板自动转为半透明 + `backdrop-filter` 毛玻璃**，背景从面板下方透出（机制与现有 `ui-surface-custom` 一致）：

| id | 背景 | 说明 |
|---|---|---|
| `solid` | 纯色 | 主题自身底色 |
| `aurora` | 极光光晕 | 径向渐变（mist/paper 同款机制），**默认** |
| `linear` | 线性渐变 | 135° 双端，对应自定义背景 gradient 模式 |
| `grid` | 网格线 | 1px 方格 22px，新增 |
| `dots` | 点阵 | 圆点网格 15px，新增 |
| `diag` | 斜纹 | 45° 斜线，新增 |
| `noise` | 噪点 | feTurbulence 细噪点，新增 |
| `image` | 图片·磨砂 | 自定义图片 + 遮罩亮度（0–90%）+ 背景模糊（0–24px）滑杆 |

### 3.3 分层与应用

```
第 1 层  主题静态层   .ui-theme-<id> 变量块（或等价查表注入），防闪烁可预置
第 2 层  用户覆盖层   内联 CSS 变量（写在 <main class="app-shell"> 上，与现状一致）：
         · accent（null=跟随主题 / #hex）→ 派生 --accent-h / --accent-soft / --on-accent
         · 状态色 success/warning/danger（默认继承主题）
         · 背景 mode=solid/gradient/image + opacity/blur/overlay（现有 --custom-* 机制保留）
第 3 层  独立槽位     终端配色（--t-* / xterm ITheme）、字体三处、水印、动效
```

派生规则（用户只选一个 accent，其余自动）：

- `--accent-h`：浅色组 `color-mix(accent 86%, black)`；深色组 `color-mix(accent 82%, white)`（深色 hover 变亮）
- `--accent-soft`：`color-mix(accent 8%, transparent)`
- `--on-accent`：**在黑字 `#171717` / 白字 `#ffffff` 中取与 accent 对比度更高者**（即 `contrast(#fff,a) >= contrast(#171717,a) ? 白 : 黑`）

> ⚠ **本轮修复的 bug**：原型初版 `--on-accent` 用了「accent 相对亮度 > 0.55 取黑字」的固定阈值，导致天蓝/琥珀/薄荷这类中亮强调色误取白字——在 3 个深色主题上主按钮文字对比度低至 **2.27–2.52:1（不可读）**。改为直接比较对比度后，深色主题取黑字达 7.1–7.9:1。实现时**必须**用 `contrast()` 比较法，不要复现阈值写法。

### 3.4 明暗 toneMode

`system / light / dark` 三态。「跟随系统」= **在用户当前所在的色彩族内**，按 `prefers-color-scheme` 在浅/深变体之间自动切换（选了暖调 → 白天陈纸、夜里乌檀）；手动点任一主题即固定为该主题。这既是对现状「背景方案联动 accent 三件套」机制的升级替代，也保证了「换明暗不丢色彩个性」。toneMode 同时兼作画廊过滤：选「浅色/深色」时，各族只显示对应明暗的卡片。

### 3.5 终端配色（独立槽位）

8 款：控制台默认 / Tokyo Night / Catppuccin Mocha / Dracula / Nord / Rosé Pine / Solarized Dark / 日光（浅色终端）。每款 = `{bg, ink, mut, prompt, ok, err, warn, selection}` + ANSI 16 色，映射 xterm.js `ITheme`（`terminal.options.theme`），走现有 `useTerminalSession` 的字体/字号变更重建链路。终端配色与 UI 主题解耦，但 Tokyo Night 与「夜阑」主题同源呼应。

### 3.6 主题文件 slc-theme.json v1

导入导出格式（嵌套 schema，导入兼容扁平旧键、未知字段忽略、非法枚举回落基底默认）：

```json
{
  "version": 1,
  "theme": "obsidian",
  "toneMode": "dark",
  "colors": { "accent": "#5e6ad2", "success": "#0a7b3e", "warning": "#b45309", "danger": "#d41313" },
  "background": { "mode": "image", "opacity": 30, "blur": 0, "overlay": 20 },
  "terminal": { "palette": "tokyo", "fontSize": 12, "lineHeight": 1.3, "cursor": "block" },
  "typography": { "ui": "geist", "log": "geist-mono", "logSize": 12 },
  "watermark": { "enabled": true, "template": "{用户} · {主机} · {时间}", "opacity": 5, "scope": "content" }
}
```

## 4. 设置界面信息架构（定稿：结构 A）

偏好页**锚点导航结构不变**（外观/日志预览/终端/布局/浮层/高级），外观与主题节为「**左紧凑主题网格 + 右大预览（420px 常驻 sticky）**」双栏：

- **卡片 1 主题**：toneMode segmented（跟随系统/浅色/深色，兼作画廊过滤）+ 主题网格（3 列，**卡片 = 真实界面缩略 + 名称 + 浅/深角标**，选中即 accent 描边；描述进 hover；无摘要条/族头徽标/色板条/圆勾）。**强调色随主题走**。
- **卡片 2 工作区背景**：8 种背景 chips（纯色/极光/线性/网格/点阵/斜纹/噪点/图片）+ 图片模式的遮罩亮度与模糊滑杆；改动即时反映在右栏大预览。
- **右栏大预览（主角）**：真实界面渲染（顶栏/页签/侧栏/工具栏/日志区/页脚），主题与背景改动即时生效；调背景滑杆时预览常驻不滚走。
- **强调色与状态色**：从一级设置撤下；覆盖入口收进「高级 · 自定义主题」。
- **终端**：配色 gallery（8 款渐变 swatch 卡）+ 仿真预览（提示符/状态输出/错误行/光标）+ 字号/行高/光标样式/闪烁/滚动回放。
- **字体 / 水印 / 动效**：能力不变，重排为卡片（水印开关收进卡片头 + 平铺预览）。
- **高级**：自定义主题（基底 + 覆盖 + 强调色/状态色覆盖 + 载入/导出/重置）+ slc-theme.json 说明 + 持久化说明。

## 6. 验收清单

1. 8 套主题逐套走查（原型 T5 全景屏 = 视觉回归清单）：日志等级色 / 面板层级 / 强调控件 / 分隔线对比度均成立；
2. **对比度**：每套主题断言 `ink≥9 / soft≥4.5 / mut≥3.3 / onAcc≥4.5 / line≥1.12`（含深色主题主按钮文字取黑字的场景）；
3. 切主题 → 强调色跟随主题；用户改过 accent → 覆盖在主题切换后保留；点「跟随主题」恢复；
4. **语义色**：深色主题下日志 ERROR/WARN 行、在线绿点、失败横幅颜色均取自该主题 `sem`，在深底上清晰；
5. toneMode=system 时模拟系统明暗切换，在**同一色彩族内**浅↔深自动切换（选暖调 → 白天陈纸、夜里乌檀）；
6. 终端配色切换即时生效且 fit 不跳动；与 UI 主题互不影响；
7. slc-theme.json 导出 → 清空 → 导入，外观完全还原；
8. 迁移：旧 key 存在时首次启动无闪烁转换，`resetUiPreferences` 后回落素白。
