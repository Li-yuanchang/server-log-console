唯一权威：`docs/ui-redesign-2026-09/prototype.html`（原型 HTML，1266 行；其 `<style>` 为设计系统 1–242 行，各屏由 `<script>` 内 `s1()`…`s15()` 渲染）

## 1. 目标

对 **S1–S15 全部 15 屏**，逐项建立「原型 / 实现 / 文档」三方对照，把不一致项记录入档并修复，使实现与原型 **1:1 一致**。

核对维度（每屏、每元素）：

1. **结构**：区块有无 / 位置 / 层级 / 顺序
2. **尺寸**：宽 / 高 / padding / gap / 圆角 / 边框
3. **颜色**：文字色 / 背景 / 边框色（核对是否走 token、是否与原型同值）
4. **字号 / 字重 / 字体族**
5. **行内样式**：原型大量使用 `style="…"`，必须逐条提取比对，不能只看类名
6. **文案**：按钮 / 标签 / 占位符 / 提示 文案一致
7. **交互态**：hover / active / disabled / focus
8. **文档一致性**：文档对该屏的记述是否与代码事实相符（文档本身也要纠错）

## 2.1 ⛔ 明确排除项（用户决策，不得当偏差"修回"）

以下为**用户有意调整的现状**，与原型不同但**保持不变**；核对时遇到须标 `[有意调整]` 并跳过，**禁止改回原型**：

1. **文件表勾选 / 批量操作条**：原型中勾选态"太突兀"（凭空插入顶开内容、抖动），已改为**移入表头槽位、选中才出现**的方案。**批量条的位置、出现方式、行高/间距均为有意设计，勿按原型回改。**
   - 涉及：`FileBrowserTableRows.tsx`、`App.tsx` 批量条分支、`theme-modern-v2.css` 批量条规则、勾选框 `align-self: stretch`。
2. **字号体系**：实现已建立 `--fs-*` 字号 token（`:root` 内，base=14px 等），**与原型 12.5px 基准不同是有意为之**（为舒适密度）。**勿按原型 12.5px 回改**；但"是否全部走 token / 是否残留裸 font-size"仍属可核对项。
3. 凡用户在会话中已明确"这样挺好/保持"的其他项，一律同样处理。

## 3. 方法（必须使用）

- **运行时取值**：把真实 CSS 拷到临时目录，配最小复刻 HTML，用无头 Chrome 读 `getComputedStyle`：
  ```
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
    --headless=new --disable-gpu --no-sandbox --hide-scrollbars \
    --force-device-scale-factor=1 --window-size=1440,900 \
    --virtual-time-budget=4000 --dump-dom file:///tmp/repro.html
  ```
- 视口：**1440×900**（文档 §3g 规定）；断点核对另测 1600/1440/1200/1024/900/800/720。
- 原型侧数值按其 `<style>` + 各屏 `style="…"` 直取，须附行号。
