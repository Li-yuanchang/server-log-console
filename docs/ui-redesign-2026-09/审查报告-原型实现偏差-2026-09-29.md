> #### G25 专项复核（撤销无效）
>
> 全局规则确实存在（`styles-sidebar-toolbar.css:401`）：
> ```css
> button:disabled { opacity: 0.48; cursor: not-allowed; }
> ```
> **但被更高优先级规则覆盖**。实测 `.ghost-button` 置 disabled 并**强制重排**后，命中的 4 条规则为：
> ```
> cursor=pointer      ← button
> cursor=not-allowed  ← button:disabled                 (opacity 0.48)
> cursor=pointer      ← .theme-modern button
> opacity=0.35        ← .theme-modern button:disabled   (未设 cursor)
> ```
> **实测结果**：`computedCursor = pointer`、`computedOpacity = 0.35`
>
> **根因**：`.theme-modern button:disabled` **只声明了 `opacity`，未声明 `cursor`**，故 `cursor` 回落到更高优先级的 `.theme-modern button { cursor: pointer }`，全局 `button:disabled` 的 `not-allowed` **被压掉**。
>
> **结论**：**G25 恢复成立**，文档的「事实反转（撤销）」判断有误——撤销依据是"规则存在"，但未验证该规则**是否实际生效**。
