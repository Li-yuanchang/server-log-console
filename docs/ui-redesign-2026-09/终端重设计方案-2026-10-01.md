# 终端工作台重设计方案 — 常规 · 好用 · 方便

更新时间：2026-10-01
状态：原型已产出并评审通过；实施调整方案见 `终端重设计实施调整方案-2026-10-01.md`（基于真实代码的分批计划）
取代：`prototype.html` 的 S5 终端屏（S5 的「终端 = 工作区第一公民」结构决策继续有效，本方案是其细化与纠偏）

## 1. 为什么重做 S5（用户反馈：不满意，要常规、好用、方便）

对照实现（`TerminalWorkspace.tsx` / `TerminalQuickBar.tsx` / `TerminalShortcuts.tsx`）与 S5 原型，问题集中在四类：

| # | 问题 | 证据 |
|---|------|------|
| P1 | **假数据 / 假提示**：「会话 1/1」硬编码；「⌃C 中断 · ⌘D 断开 · 拖入文件 = SFTP 上传」「⌘/ 呼出 · 长按编辑」均无对应实现 | `TerminalWorkspace.tsx:67,304`、`TerminalQuickBar.tsx:40`、recon S4-S6 §S5 |
| P2 | **非常规交互**：AI 占强调色主按钮位；快捷命令「长按编辑」无暗示无入口；底部常驻提示条占用垂直空间且内容不真实 | S5 原型 + 实现 |
| P3 | **缺常规终端基建**：无终端内多标签、无状态栏、无终端内查找、无右键菜单——对比 Xshell/FinalShell/Tabby 属于"标配" | 实现盘点 |
| P4 | **工具行语义混乱**：分屏/弹出/AI/收起平铺，「收起」与视图 seg 重复 | S5 原型 |

## 2. 设计原则

- **常规**：五段式结构对标成熟 SSH 客户端——`工具行(视图 seg + 动作) → 终端标签条 → 终端 → 快捷命令行(可开关) → 状态栏`。不发明手势类交互，所有快捷键走平台惯例。
- **好用**：界面上出现的每条信息都必须真实（连接状态/时长、重试进度、标签状态点）；每个可见动作都必须有实现承接；不造不存在的快捷键。
- **方便**：复用已有后端能力降低实施成本——状态栏资源迷你条复用网关 10s 采集，重连回放复用 detach/transcript，上传复用统一传输体系；补齐终端 cwd 与文件浏览器双向联动。

## 3. 结构决策（按屏）

### 3.0 两层标签的关系（实施必读）

上层工作区 tab（服务器会话）与下层终端标签是**包含关系，不是联动关系**：

- 每个工作区 tab 拥有**独立的一组终端标签**（连同各自的分屏布局），随上层 tab 切换**整套替换**，互不共享、互不逐个跟随——与检索条件、文件浏览位置按工作区隔离是同一套心智
- 下层 ⌘T 默认新开一条**到当前服务器**的 SSH 会话；⌘W 关闭当前标签；重名自动加序号（`127.38 · 2`）
- 下层切换只改变终端焦点，不影响上层，也不影响其他工作区
- **唯一例外：堡垒机工作区**——可在同一工作区内为多个资产各开终端标签（经堡垒机连接，沿用现有 JumpServer 链路），标签名 = 资产名；这些标签仍只存在于该堡垒机工作区内

| 屏 | 决策摘要 |
|----|---------|
| T1 | 五段式常规布局；删除「会话 n/n」「假提示条」「收起按钮」；AI 降为图标；状态栏 = 连接状态/时长 + CPU/内存/磁盘迷你条（点击开监控抽屉） |
| T2 | 终端内多标签（⌘T/⌘W），标签名 = 服务器别名 + 状态点；分屏保留二叉树 + 焦点窗格 accent 内框；分屏布局收进「分屏 ▾」菜单 |
| T3 | ⌘F 悬浮查找条（命中计数/导航/Aa/正则，接 xterm-addon-search）；右键菜单只放真实能力；「在文件目录中打开」补齐 cwd 反向联动；选中即复制、右键粘贴为默认 |
| T4 | 断线零弹窗：标签红点 + 一行横幅（原因 + 自动重试 n/5 + 立即重连）+ 状态栏红态；重试 5 次失败后停止保持手动重连；重连回放 transcript |
| T5 | 拖拽上传真实化：悬停出现当前目录遮罩，释放即 SFTP 上传；进度走统一传输体系（toast + 传输记录抽屉）；同名询问与文件浏览一致 |
| T6 | AI 抽屉非模态侧挂，建议命令 ↵ 直发焦点窗格；危险命令拦截/备份门控不动（ai-service）；API 配置只在设置中心（落实 S5-21） |
| T7 | 弹出 = 同会话第二块屏：精简结构（标签条 + 终端 + 状态栏），主窗占位可收回；全局单弹出实例机制不变 |
| T8 | 空态单一主按钮（连接当前服务器）+ 最近连接 chips；无会话时所有动作禁用置灰；标签条隐藏 |
| T9 | 快捷命令 = 常规 CRUD 对话框（预设保护 / 拖拽排序 / 恢复预设）；新增 `{CWD}` 变量按终端当前目录展开 |
| T10 | 工具行 7 按钮 + 标签条的动作明细（见 §3.1） |

### 3.1 工具行动作明细（T10，实施规格）

统一规则：**禁用条件 = 无任何会话**（对应 T8 置灰态）；作用于**焦点窗格**；不新造快捷键（⌘D/⌘W 仅桌面端注册，浏览器端保留按钮入口）。

| 控件 | 行为 |
|------|------|
| 终端标签条 | 单击切换焦点；⌘T 新建到当前服务器的会话；⌘W 关闭（先 detach，90s 可恢复）；hover 显 ×，桌面端中键关闭；标签右键 = 关闭 / 关闭其他 / 全部关闭；状态点 绿=已连接 · 橙=连接中 · 红=断开 · 灰=手动断开 |
| 查找 | ⇄ 呼出/关闭悬浮查找条；⌘F 同效；Esc 关闭；计数 n/N、⏎/⇧⏎ 导航、Aa、.*；实现 = xterm-addon-search |
| 分屏 ▾ | 单窗格主点击 = 直接左右分屏；已分屏主点击 = 菜单（左右 ⌘D / 上下 / 三分格 / 关闭当前窗格[仅一窗格时置灰]）；新窗格 = 新建到当前服务器的会话并移焦点（沿用现有 per-pane session 模型） |
| 上传 | 系统文件选择器（可多选）→ 焦点窗格 cwd；与拖拽同一通道（T5）；同名询问 |
| 快捷命令 | 开关底部命令行（默认开，持久化）；chip 单击 = 发送并执行，⌘点 = 仅填入；右键 chip = 发送 / 仅填入 / 编辑 / 删除；「管理」= T9 对话框 |
| AI | 开关抽屉（⌘J）；引用焦点窗格选中；建议命令 ↵ 直发；危险命令门控不动；API 配置只在设置中心 |
| 弹出 | 弹出整个终端组（全部标签 + 分屏）；桌面 = Electron 窗口 / Web = Document PiP；主窗占位可收回；全局唯一实例 |
| ⋯ 更多 | 清屏（只清本地回滚缓冲，**不向远端发不可见字符**——JumpServer 网关红线）；重连（无断开置灰）；断开（detach）；在文件目录中打开（切文件视图并定位 cwd）；导出会话记录（下载回滚缓冲为 .log）；终端设置（→ 设置中心-外观） |

快捷键总表（桌面端）：⌘T 新建标签 · ⌘W 关闭标签 · ⌘F 查找 · ⌘J AI · ⌘D 左右分屏 · Ctrl+L shell 清屏（透传不拦截）· ⌘1-9 切换工作区（既有）。浏览器端仅注册 ⌘F/⌘J。

## 4. 删除清单（相对现 S5 / 现实现）

1. 「会话 1/1」假 chip → 终端内多标签承载真实会话
2. 底部「⌃C 中断 · ⌘D 断开 · 拖入上传」提示条 → 删除；⌘D 分屏快捷键仅保留在分屏菜单提示
3. 「⌘/ 呼出 · 长按编辑」→ 右键编辑 + 「管理」对话框
4. AI 强调色主按钮 → 工具行图标（⌘J）
5. 「收起」按钮 → 切视图走 seg
6. 独立窗口恒假的 `showStandaloneConnectionStrip` 分支 → 实施时一并清理

## 5. 实施映射（改动落点，供排期估算）

| 能力 | 落点 | 成本 |
|------|------|------|
| 终端内多标签 | `useWorkspaceSessionManager` / `TerminalWorkspace` 拆分 pane 状态为数组 | 中 |
| 状态栏 + 资源迷你条 | 新组件；数据复用 server-status 采集（10s 环形缓冲已有） | 低 |
| ⌘F 查找 | `@xterm/addon-search` + 悬浮条组件 | 低 |
| 右键菜单 | 替换现自研选区浮层，`rebuildSelectionFromBuffer` 可随简化 | 中 |
| 拖拽上传 | 复用 `useFileTransfer.handleFileDrop`，目标目录取终端 cwd | 中 |
| 断线横幅 | `useTerminalSession` 断线状态已有，补 UI + 重试计数展示 | 低 |
| {CWD} 变量 | `TerminalShortcuts` 发送前替换 | 低 |

## 6. Review 方式

按既有流程逐屏给「通过 / 改 X」；T1 为主验收线（五段式结构 + 状态真实性），T2/T3 为次（多标签与查找是本期新增能力），其余为状态补充屏。
