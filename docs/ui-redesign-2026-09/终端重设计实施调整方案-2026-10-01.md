```
└─ 废弃: TerminalShortcuts.tsx（侧板）、TerminalPane.tsx、TerminalSplitView.tsx（树算法迁走后删）
```

**会话模型升级（核心，批2）**：

```ts
// types.ts · WorkspaceSessionState 增量
terminalTabs: TerminalTabState[];   // { tabId, sessionId, kind: "server" | "asset", assetKeyword? }
activeTerminalTabId: string;
// 迁移：旧 terminalSessionId 非空 → terminalTabs=[{…}]，读侧兜底一个版本后删除旧字段
// 分屏布局（split tree）保留内存态、不持久化——终端会话本身不跨重启，持久化无收益
```

- 渲染策略：**全部标签挂载、非激活 `display:none`**（保 live 输出与回滚），标签上限 **8 个**（xterm 实例内存护栏，超出时 + 号置灰提示）
- 堡垒机工作区：`kind:"asset"` 标签走既有 `connectToJumpServerAsset`（`/关键字` 自动选资产链路），标签名 = 资产名

## 4. 分批实施（每批 = 一个可验证版本）

### 批3 · 分屏统一进标签（≈1.5d）

### 批6 · 断线横幅 + 弹出对齐（≈1d）

### 批8 · 清理与样式收口（≈0.5d）

## 5. 与原型（目标态）的差异取舍

| 点 | 原型（目标态） | 本期实现 | 理由 |
|----|----------------|----------|------|
| 弹出范围 | 整个终端组（全部标签+分屏） | 当前激活标签 | `openPipWindow` 协议按单 `terminalSessionId` 传参；组弹出需协议扩展，收益/成本不匹配 |
| 上传目标目录 | "终端当前目录" | 应用层 cwd（初始/联动目录），UI 显示实际值 | shell 实时 cwd 不可得（OSC7 对 JumpServer 不可用） |
| 分屏布局持久化 | 未承诺 | 不持久化（内存态） | 会话本身不跨重启 |
| 标签数量 | 未承诺 | 上限 8 | xterm 实例内存护栏 |

## 6. 风险与红线

1. **JumpServer**：清屏只清本地回滚缓冲；`resetTerminalKeepalive` 空实现保持；资产标签只走既有资产连接链路
2. **双轨拆除必须在批3 一次完成**（App.tsx :1591/:1611 互斥 + :3257 分支），否则单屏/分屏继续漂移
3. **PiP DOM 搬迁**（`togglePip` 遍历 styleSheets）本期不动，风险隔离；批8 仅评估
4. **App.tsx 收口**：终端 state（splitMode/overlay/panelOpen…）随批2 迁入 `useTerminalTabs`，App.tsx 只留装配——顺着 §3f 方向走但不扩大范围
5. 每批结束跑一次 `docs/对齐偏差总账` 口径的自查（原型 vs 实现截图并排）
