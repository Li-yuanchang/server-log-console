## 二、组件设计

### `ui/EmptyWorkbench.tsx`（新，宽屏大屏空态统一组件）

```ts
export type EmptyWbStep = {
  title: string; desc: string;
  state?: "cur" | "wait" | "done";
  action?: { label: string; kind?: "pri" | "ghost"; onClick?: () => void; disabled?: boolean };
};
export type EmptyWbRow = {
  dot?: "ok" | "idle" | "red" | "warn";
  title: string; meta?: string;          // meta 走 mono
  action?: string; onAction?: () => void;
};
export type EmptyWbPanel = { title: string; link?: string; onLink?: () => void; rows: EmptyWbRow[] };
export type EmptyWorkbenchProps = {
  icon: ReactNode; eyebrow: string; title: string; sub: string;
  steps: EmptyWbStep[];
  live?: string;                          // 连接中 mono 状态行（含打点动画）
  panel?: EmptyWbPanel;                   // 右栏情境面板；无则单列
  tip?: ReactNode;                        // 右栏提示卡
  keys?: { kbd: string; label: string }[];// 触屏容器隐藏
  onStepClick?: never;                    // 不需要
};
```

结构：`.empty-wb > .empty-wb-grid(.no-side) > main（eyebrow/title/sub/live/steps/keys）+ aside（panel/tip）`。
**窄档自适应**（`@container slc-sp (max-width: 799.9px)`）：aside 隐藏、keys 隐藏、panel.rows 降级为 chips 行（组件内同时渲染 `.empty-wb-chips`，宽档 `display:none`）——与原型 08 屏一致，不另写第二套 JSX。

### 五态状态卡（`SidebarPanel.tsx`）

```
状态映射：showServiceOfflineState → warn（服务离线）
        connectionTestStatus && !connected && isBusy? → err（连接失败）
        isBusy || (selectedServer && connectionTestStatus===null) → connecting（连接中）
        selectedServer && connectionTestStatus?.connected → ok（已连接）
        其余 → idle（待命）
```
收起态两行：L1 `状态指示 + 状态词 + chevron`；L2 上下文（connecting=阶段 · 名；ok=名 · path；err=host · 原因；warn=重试 · 地址；idle=提示）。
展开态：kv 网格（本地服务/服务器/主机/路径）+ 动作行（按状态：重试/检查服务/连接设置/重新连接）。

## 三、与原型的偏差（结合实际，逐条记录）

1. **目录为空保持列内紧凑模板**：真实布局是「目录树 + 内容列」双列，空态在内容列内，不是整幅工作区；放 800px 双栏工作台会挤爆列宽。实装保留现模板，仅加副按钮「上传文件」（若处理器可用）。
2. **底部状态卡折叠态由 30px 改为两行自适应高**：覆盖 `theme-modern-v2.css:2725-2732` 的对齐规则。理由：用户截图确认一行式不可用；台阶仅出现在「终端开启 + 操作记录隐藏」组合，收益大于代价。原注释保留并追加说明。
3. **右栏面板只做有数据源的**：「最近检索」「常用位置」无现成数据源，不造数——检索空态无右栏（单列 + tip），未选服务器右栏 = 「快速连接」（取 `servers` 前 4 台，点击即连，真实存在）；服务离线右栏 = 服务诊断（`localServiceBase` + `localServiceStatusText`）；无服务器右栏 = 导入来源（FinalShell/Xshell/手动新增，均有真实处理器）。
4. **SP 状态行移除，概览并入选服层**：`SidepanelStatusbar` 从 App.tsx 摘除；`ServerPickerOverlay` 顶部新增「连接概览」kv 区块（复用原 detailLines 数据），保住 v3「移动档概览可达」的修复不回退。
5. **检索空态按钮**：保留「查看检索示例（主）」「打开文件目录」；「读取尾部」出现条件琐碎（filePath 且非 busy），收进键位提示，不再常驻按钮。
6. **小态不造按钮**：SSH 隧道「新建隧道」= `setShowForm(true)`（真实存在）；命令面板无匹配的「清空」需要 onChange 引用（存在，`props.onQueryChange`? 若无则只加提示文案）。
