记录时间：`2026-09-29`

---

## 1. 字体族的三条独立链路（实测确认）

项目里字体族并非单点可控，而是**分布在三个层级**：

| 层级 | 位置 | 当前值 | 是否走 CSS 变量 |
|------|------|--------|----------------|
| **界面字体** | `--app-font-family`（`theme-modern.css`） | `"Geist","Inter",-apple-system,…` | ✅ 变量 |
| **等宽（CSS 侧）** | `--mono`（`theme-modern.css`）/ `--mono-font-family` / `--v2-mono`（`theme-modern-v2.css:24`） | `"Geist Mono","SFMono-Regular","Menlo","Consolas",monospace` | ✅ 变量（但**三处平行定义**） |
| **终端字体（JS 侧）** | `useTerminalSession.ts:230` `new Terminal({ fontFamily: … })` | `'SFMono-Regular', 'Consolas', monospace` | ❌ **硬编码在 JS** |

### 关键结论

1. **终端字体族无法靠改 CSS 变量生效** —— xterm 在实例化时把 `fontFamily` 写入 JS 配置，
   后续改 CSS 变量不会应用到已创建的终端实例。
2. `--mono` / `--mono-font-family` / `--v2-mono` 是**三个平行变量**，分别被引用
   3 处 / 8 处 / 8 处。要做统一控制需收敛为单一来源。
3. `.log-line` 的字体族来自 `styles-viewer-search.css` 的硬编码，
   而非 `--mono-font-family`（需进一步确认是否已被 v2 覆盖）。

### 实施建议（若要做「日志字体族」独立配置）

- **最小改动**：把 `--v2-mono` 的值改为 `var(--mono)`，然后只改 `--mono` 一处，
  即可同时驱动 CSS 侧全部等宽场景（省去改 19 处的风险）。
- **终端需额外处理**：xterm 必须在字体族变化时**重建实例或调用**
  `term.options.fontFamily = …` 并触发 `fit()` 重排，否则设置不生效。

## 4. 与其他改动的交叉风险

- `--mono` / `--mono-font-family` 的定义刚在 A1 修复中补入 `theme-modern.css`，
  值为原型规格 `"Geist Mono","SFMono-Regular","Menlo","Consolas",monospace`。
- 若后续把 `--v2-mono` 改指 `var(--mono)`，需确认 v2 无其他地方假设二者独立。

## 5. 待执行的收敛重构（零视觉变化，需在 agent 集成后做）

三套等宽变量实测引用面：

| 变量 | 定义位置 | 引用数 | 当前值 |
|------|---------|-------|--------|
| `--mono` | `theme-modern.css:41` | **11** | `"Geist Mono","SFMono-Regular","Menlo","Consolas",monospace` |
| `--mono-font-family` | `theme-modern.css:42`（=`var(--mono)`） | **8** | 同上（间接） |
| `--v2-mono` | `theme-modern-v2.css:24` | **9** | 同上（**独立重复定义**） |

**三套当前值完全相同**（已 grep 确认不存在第二种取值），故可安全收敛：

```diff
  /* theme-modern-v2.css:24 */
- --v2-mono: "Geist Mono", "SFMono-Regular", "Menlo", "Consolas", monospace;
+ --v2-mono: var(--mono);
```

**收益**：把「日志字体族」的实施面从 19 处降到 1 处（只改 `--mono`）。

**回归验证要求**：改后需截图比对 **日志区 / 终端 / 侧栏 / 面包屑** 四处
（`theme-modern-v2.css:1628` 有 `var(--v2-mono, ui-monospace, Menlo, monospace)` 带 fallback，改后 fallback 仍在，安全）。
