## 一、改造点清单（原型能力 → 落点）

### 2. 生效链路 — `App.tsx`

- `appShellClassName`（L3137）：`ui-surface-*` → `ui-theme-${resolvedThemeId} ui-bg-${uiBackground}${uiBackground!=="solid"?" ui-bg-fancy":""}`；经典主题分支不动。
- `appShellStyle`（L3138-3159）：accent 覆盖时 JS 内 `contrast()` 比较法派生并内联 `--accent/--accent-strong/--accent-soft/--on-accent`；保留 `--custom-background-image/--custom-image-overlay/-alpha/-blur`（image 层用）；删除废弃的 custom 颜色变量。
- Electron immersive / 动态背景 / 水印挂载点不动。

### 3. 主题 CSS — `theme-modern.css`

- 在 `.ui-surface-*` 块（L107-143）位置改为 **8 个 `.theme-modern.ui-theme-<id>` token 块**（每组：bg/panel×3/ink×3/line×2/accent 三件套/on-accent/green/red/amber 及 soft/shell×3/sidebar×2/--on-ink/--dot-idle）。基础 `.theme-modern` 块（L51-105）保留为兜底（值=晨白）。
- 背景层：`.theme-modern.ui-bg-aurora/linear/grid/dots/diag/noise/image` 覆写 shell 背景（径向/线性渐变、网格/点阵/斜纹用 background-image 平铺、噪点用 data-uri feTurbulence、image 用 `--custom-background-image` + overlay/blur 变量）；`.ui-bg-fancy` 下 `.main-panel/.sidebar-panel/.toolbar-panel/.workspace-panel/.advanced-panel` 转半透明 + `backdrop-filter`（复用 L204-238 的 ui-surface-custom 面板规则模式）。
- 旧 `.ui-surface-*` / `.ui-custom-background-*` 块删除；`styles-layout.css:13-26` 的无前缀 `.app-shell.ui-surface-*` 经典渐变一并删除（防污染）。
- `:root:has(.theme-modern){background:#fafafa}`（L43-45）→ 每主题 `:root:has(.ui-theme-<id>)` 覆写（深色主题 html 底色同步）。

### 4. 首屏 / Electron — `index.html` + `apps/electron/main.cjs`

- `index.html` L8-19 防闪烁脚本：读 `ui-theme-preset` + `ui-tone-mode` + `prefers-color-scheme` → 解析出主题 id → `documentElement.dataset.skTheme` + 按内置 8 色表设置 `html` 背景与骨架 `--sk-*`；mist/paper 旧分支删除。
- `main.cjs` 主窗/PiP `backgroundColor`：本轮先改中性 `#fafafa`→保持，但登记**待办**：需 preload IPC 把渲染层主题 bg 回传主进程才能完全消除深色主题冷启动闪色（渲染层 index.html 已兜住 web 层）。

### 5. 设置中心 — `ConnectionSettingsWorkspace.tsx`

- 删除：`SURFACE_OPTIONS`（L18-23）及其缩略卡（L920-945）、自定义背景整卡（L946-1098，其图片选择 `getPathForFile` 逻辑 L329-341 迁移复用）。
- 外观节（pref-appearance L906 起）重建为结构 A：主题网格（8 张卡 = MiniWin 真实缩略 + 名称 + 浅/深角标，MiniWin 组件从原型移植）+ toneMode seg；工作区背景 8 chips + 图片模式遮罩/模糊滑杆。
- 终端节（pref-terminal）加 8 款配色 gallery（渐变 swatch 条，样式对齐原型 T2）。
- 高级节（pref-advanced）加「强调色覆盖」：跟随主题 + 预设圆卡 + 自定义取色。
- Props：`preferenceSection`（L45-116）与 App.tsx 装配处（L4426-4489）同步扩字段。

### 6. 终端 — `useTerminalSession.ts` + 链路

- 新增 `terminal-schemes.ts`（或并入 useUiTheme 导出）：8 款 ITheme（background/foreground/cursor/selection + ANSI 16 色，取自各官方配色）。
- `useTerminalSession` Options 加 `terminalScheme`；创建（L264-304）与更新 effect（L320-340）用 scheme 的 ITheme 替换写死的 one-dark 16 色；`terminalBackgroundColor` 默认改取 scheme.bg。
- 链路：App → TerminalPanel(TerminalWorkspace.tsx L231) → TerminalTabPane/useTerminalSession，照 `terminalFontFamily` 模式加 prop。

### 7. 语义色/覆盖派生（JS）

`onAccent = contrast(#fff,a) >= contrast(#141414,a) ? '#fff' : '#141414'`（WCAG 相对亮度），放 `useUiTheme.ts` 导出，App 内联注入；`--accent-h = 浅色系 mix black 14% / 深色系 mix white 18%`。

### 修复的 bug

1. **卡片被压扁**：`.slc-theme-card` 是 `<button>`，被全局 `:where(.theme-modern) button { height: var(--ctl-h) }`(28px) 钉死，子元素溢出重叠 → 卡片类补 `height:auto`。
2. **html 底色不跟随**：index.html 防闪烁写内联 style（优先级最高），切主题不更新 → App 加 effect 同步。
3. **`--on-accent` 阈值法**（历史）：改用 `contrast()` 比较法。
