主题选款 · 符合本系统风格

先读了本项目的设计规范（THEME-SPEC + Vercel/Cal 参考），确认这套系统的基因是 Vercel Geist 单色极简。所以主题不是"换一整块调色"，而是「灰阶骨架不动 + 一个克制的功能色」。

本系统的设计 DNA（摘自项目自己的规范文档）：
· 「纯白底 + 黑白主调 + Vercel Blue 强调 + Geist 字体」THEME-SPEC.md
· 「灰阶就是系统本身，颜色是功能性的、绝不装饰性」；用 #171717 而非纯黑　vercel-design.md
· 「纯粹灰阶品牌色，靠单色体现自信」　cal-design.md

所以这 8 套全部遵循：只有 bg/panel/ink/line 走灰阶，仅 accent（按钮/选中/链接/进度）带一点功能色，且都是低饱和、不抢日志的克制色。渲染用的是真实产品布局（浅色侧栏 + 深色日志区 + 工具栏），不是通用小卡片——请在这个真实语境下判断。
