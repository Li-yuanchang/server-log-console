# Product Requirements

## 1. Background

Operations and developers need a unified way to search Linux server logs, inspect historical and live output, and export findings to local files. Existing workflows depend on FinalShell and manual shell commands, which makes knowledge transfer difficult and creates inconsistent operating habits across environments.

## 2. Product Goal

Build a Chrome extension plus local gateway service that lets users:

- import non-production server definitions from FinalShell
- search remote log files by keyword and date
- view real-time log streams
- export search results or live snippets to local files
- avoid direct access to production servers imported from FinalShell

## 3. User Roles

- Developer: searches test and development logs during feature debugging
- QA: verifies release behavior through target log queries
- Support engineer: investigates issue timelines and exports evidence

## 4. Core Scenarios

### 4.1 Historical search

The user selects a server and log file, enters a date and keyword, then receives matching lines with context and command preview.

### 4.2 Targeted troubleshooting

The user imports servers from FinalShell, picks a development host, searches a specific reimbursement id or SQL fragment, and downloads the result file locally.

### 4.3 Live observation

The user opens a live tail stream for a file, watches new lines arrive in the extension, and exports the current visible snippet when needed.

### 4.4 Safe server discovery

The system reads FinalShell folders and connection metadata automatically, but blocks imported entries under the `生产` group from being used.

## 5. Scope

### 5.1 In scope

- Chrome extension popup UI
- local Node.js gateway
- FinalShell metadata import
- SSH-based log search and live tail
- result export to local file
- production-group access blocking for FinalShell imports

### 5.2 Out of scope for current phase

- direct password decryption from FinalShell
- cloud multi-user deployment
- role-based approval workflow
- server-side persistent database
- full-text indexing engine

## 6. Functional Requirements

### FR-1 Server import

- The gateway shall read FinalShell folders and connection files from the local machine.
- The gateway shall expose imported server summaries through an API.
- Imported entries under the `生产` group shall be filtered out.

### FR-2 Server listing

- The extension shall display both built-in demo servers and imported FinalShell servers.
- The UI shall show metadata including source, group path, auth type, and base path.

### FR-3 Log search

- The user shall be able to submit a server id, file path, date, keyword, regex flag, and context lines.
- The gateway shall translate the request into a safe shell command template and run it through SSH.
- The response shall include command preview, raw output, parsed matches, and truncation state.

### FR-4 Real-time tail

- The user shall be able to start a live tail session for a file.
- The gateway shall stream new log content over WebSocket.
- The client shall show connection, error, and closed states.

### FR-5 Export

- The user shall be able to export historical search output.
- The user shall be able to export captured live snippet content in a later iteration.

### FR-6 Safety constraints

- The system shall not accept raw shell commands from the UI.
- The system shall require SSH credentials from environment variables or a mapped credential object.
- The system shall reject FinalShell imported servers under `生产`.

## 7. Non-functional Requirements

- Search requests should return within 20 seconds under normal network conditions.
- The gateway should fail with readable error messages when credentials are missing.
- UI state should remain simple enough for popup use and not require opening a full tab in the first phase.
- Sensitive credentials must not be stored in the extension.

## 8. Risks

- FinalShell password field may be encrypted and not directly reusable.
- Large log files may cause slow grep execution on weak hosts.
- Mixed log formats may require profile-specific date filtering later.

## 9. Acceptance Criteria

- FinalShell import can read local connection definitions and exclude `生产` servers.
- A development or test host can be searched through real SSH execution.
- Live tail can connect and display incremental output.
- Search results can be exported through the extension.
- Design and implementation documents are present and readable by future maintainers.
