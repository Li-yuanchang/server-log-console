## 当前真实启动命令

| 任务 | 命令 |
|---|---|
| extension 开发 | `npm --prefix apps/extension run dev` |
| extension 构建 | `npm --prefix apps/extension run build` |
| gateway 开发 | `npm --prefix apps/gateway run dev` |
| gateway 构建 | `npm --prefix apps/gateway run build` |
| Electron 启动 | `npm --prefix apps/electron run start` |
| Electron macOS 打包安装 | `npm --prefix apps/electron run release:mac` |

根目录当前只有 `build:extension` 脚本。排查启动、打包、服务问题时应优先进入对应 workspace 执行命令。
