# Server Log Console 业务功能总览

更新时间：`2026-06-29`

本文按当前代码重新梳理业务功能，用于回答三个问题：

- 当前系统到底提供哪些业务能力
- 每个能力的前端入口、网关接口和核心代码在哪里
- 后续排查问题时应该从哪条链路切入

## 1. 产品定位

Server Log Console 当前已经不是单纯的日志搜索页，而是一个本地 SSH 运维工作台。

核心目标：

- 复用本机已有连接配置，快速进入目标服务器
- 在不下载整份日志的情况下检索、阅读、定位大日志
- 在同一工作台完成目录浏览、文件操作、实时 tail、终端、批量命令、隧道和问题留痕
- 同时支持 Electron 桌面应用、Chrome 扩展页面和浏览器访问形态

## 2. 运行形态

| 形态 | 入口 | 说明 |
|---|---|---|
| Electron 桌面应用 | `apps/electron/main.cjs` | 加载本地 extension 构建产物，后台启动或导入 gateway，提供桌面窗口、托盘、PiP/独立窗口能力 |
| 浏览器开发模式 | `apps/extension` + `apps/gateway` | 前端 Vite 和 gateway 分别启动，适合开发调试 |
| Chrome 扩展 | `apps/extension/dist` | 扩展前端访问本地 gateway，需本地服务可用 |
| gateway 静态托管 | `apps/gateway/src/index.ts` | gateway 存在 extension dist 时可直接托管前端静态文件 |

当前真实脚本入口：

| 任务 | 命令 |
|---|---|
| extension 开发 | `npm --prefix apps/extension run dev` |
| extension 构建 | `npm --prefix apps/extension run build` |
| gateway 开发 | `npm --prefix apps/gateway run dev` |
| gateway 构建 | `npm --prefix apps/gateway run build` |
| Electron 启动 | `npm --prefix apps/electron run start` |
| Electron macOS 打包安装 | `npm --prefix apps/electron run release:mac` |

注意：根 `package.json` 当前只保留 `build:extension`，不要按旧 README 中的根脚本口径排查启动问题。

## 3. 业务功能域

### 3.1 服务器与连接管理

业务能力：

- FinalShell 导入
- Xshell 导入
- 手动服务器新增、编辑、删除
- 凭证保存、凭证状态展示、连接测试
- direct / bastion / bastion-target 三种连接类型
- JumpServer 资产搜索与二跳路由配置
- 按 workspace 保存当前服务器和状态

前端入口：

- `SidebarPanel.tsx`
- `ConnectionSettingsWorkspace.tsx`
- `useServerManagement.ts`
- `useServerConnection.ts`
- `useImportSettings.ts`
- `useWorkspaceSessionManager.ts`

网关入口：

- `GET /api/servers`
- `POST /api/servers/manual`
- `DELETE /api/servers/:serverId`
- `GET /api/servers/:serverId/credential`
- `POST /api/servers/:serverId/credential`
- `GET /api/servers/:serverId/route`
- `POST /api/servers/:serverId/route`
- `POST /api/servers/:serverId/test-connection`
- `GET /api/import/tools`
- `GET /api/import/finalshell`
- `GET /api/import/finalshell/settings`
- `POST /api/import/finalshell/settings`
- `GET /api/import/xshell`
- `POST /api/servers/:serverId/jumpserver/assets`
- `POST /api/servers/:bastionId/jumpserver/browse-assets`

核心服务：

- `apps/gateway/src/modules/servers/server-registry.service.ts`
- `apps/gateway/src/modules/servers/local-config.service.ts`
- `apps/gateway/src/modules/servers/credential-resolver.service.ts`
- `apps/gateway/src/modules/servers/strategies/finalshell-strategy.ts`
- `apps/gateway/src/modules/servers/strategies/xshell-strategy.ts`
- `apps/gateway/src/modules/logs/ssh-executor.service.ts`
- `apps/gateway/src/modules/logs/strategies/*`

主要风险：

- `serverId` 变化会影响连接状态、文件浏览、搜索结果、终端、实时日志和 workspace 恢复
- JumpServer 分支和 direct 分支必须保持相同的文件/日志/终端契约
- FinalShell/Xshell 导入配置是本机私有状态，问题复现依赖用户本地环境

### 3.2 文件浏览与文件操作

业务能力：

- 远程目录树与目录内容表格
- 路径栏、历史路径、目录筛选、排序、多选
- 文件预览、编辑保存
- 上传、分片上传、下载
- 删除、重命名、新建目录、压缩、解压
- 传输记录、复制路径、本地文件定位

- `FileBrowserGrid.tsx`
- `FileBrowserPathbar.tsx`
- `FileBrowserActions.tsx`

- `FilePreviewDialog.tsx`
- `TransferHistoryDialog.tsx`
- `TransferHistoryDropdown.tsx`
- `useFileOperations.ts`
- `useFileTransfer.ts`
- `useTransferHistory.ts`

网关入口：

- `POST /api/logs/files`
- `POST /api/files/preview`
- `POST /api/files/save`
- `POST /api/files/download`
- `POST /api/files/upload`
- `POST /api/files/upload/start`
- `POST /api/files/upload/chunk`
- `POST /api/files/upload/finish`
- `POST /api/files/delete`
- `POST /api/files/rename`
- `POST /api/files/mkdir`
- `POST /api/files/compress`
- `POST /api/files/extract`

核心服务：

- `apps/gateway/src/modules/logs/file-browser.service.ts`
- `apps/gateway/src/modules/logs/file-transfer.service.ts`
- `apps/gateway/src/modules/logs/strategies/connection-strategy.ts`

主要风险：

- 文件操作同时依赖 SFTP 能力和远程 shell 命令能力
- 大文件下载/上传必须关注进度、取消、失败清理和传输记录一致性
- 样式入口在文件浏览、dialog、toast、responsive 多处，排查 UI 问题要看 `docs/style-architecture.md`

### 3.3 日志搜索

业务能力：

- 单文件异步搜索任务
- 多关键字：短语、任一、全部
- 排除关键字
- 正则模式
- 日期和时间范围
- 上下文行
- 搜索进度、阶段信息、快速结果、完整扫描结果
- 多文件搜索
- 搜索结果 tab、二次筛选、导出
- 命中点击跳转到日志上下文或切片位置

前端入口：

- `SearchQueryPanel.tsx`
- `SearchProgressPanel.tsx`
- `SearchToolbarActions.tsx`
- `VirtualLogViewer.tsx`
- `useLogViewer.ts`
- `useSearchTimer.ts`

网关入口：

- `POST /api/logs/search`
- `POST /api/logs/search/tasks`
- `GET /api/logs/search/tasks/:taskId`
- `POST /api/logs/search/multi`
- `POST /api/logs/export`

核心服务：

- `apps/gateway/src/modules/logs/logs.service.ts`
- `apps/gateway/src/modules/logs/log-search-task.service.ts`
- `apps/gateway/src/modules/logs/multi-file-search.service.ts`
- `apps/gateway/src/modules/logs/command-builder.ts`

主要风险：

- 搜索任务返回 `quickResult`、`result`、progress 字段，前端必须处理运行中和完成态两套数据
- 日志预览和文件目录共用 viewer 区，切换时要保持 `results`、`resultTabs`、`activeViewerTabId`、`activeLogView` 一致
- 大文件命中跳转不能靠粗略比例，优先使用 line-context 或明确偏移策略

### 3.4 大文件阅读与定位

业务能力：

- 日志元信息读取
- `offset + length` 切片读取
- 自动完整行裁切
- 上一段、下一段、回到底部、跳到开头、比例拖动
- 搜索命中行上下文
- 阅读器右侧 rail / 进度条 / 概览拖动
- 实时跟随与手动阅读互斥控制

前端入口：

- `VirtualLogViewer.tsx`
- `useLogViewer.ts`
- `useLiveFollow.ts`
- `useSliceCache.ts`
- `styles-file-reader.css`
- `styles-viewer-search.css`
- `styles-responsive.css`

网关入口：

- `POST /api/logs/meta`
- `POST /api/logs/slice`
- `POST /api/logs/line-context`

核心服务：

- `apps/gateway/src/modules/logs/log-slice.service.ts`
- `apps/gateway/src/modules/logs/ssh-executor.service.ts`

主要风险：

- 滚动条比例、切片 offset、文件大小、下一段 offset 不能混用
- “回到底部”应优先定位文件尾部或最后一行，而不是依赖 UI 百分比计算
- 搜索结果跳转后必须给用户明确的选中目标，否则会感觉迷失

### 3.5 实时日志

业务能力：

- WebSocket 实时 tail
- 关键字过滤
- 自动跟随、暂停滚动、恢复到底部
- 实时片段下载
- 连接关闭和错误提示

前端入口：

- `useLiveFollow.ts`
- `VirtualLogViewer.tsx`
- `SearchToolbarActions.tsx`

网关入口：

- `POST /api/logs/live`
- `WS /ws/live`

核心服务：

- `apps/gateway/src/modules/logs/logs.service.ts`
- `apps/gateway/src/modules/logs/command-builder.ts`
- `apps/gateway/src/index.ts` 中 `/ws/live` 处理段

主要风险：

- 用户主动滚动阅读时不能被实时跟随强行拉到底
- workspace/server 切换时必须关闭旧 live session
- WebSocket 与 SSH 进程清理要同步，避免后台 tail 残留

- xterm.js 内嵌终端

- detach / reattach
- Electron 独立终端窗口
- 分屏终端
- 快捷命令面板
- AI 辅助命令面板
- JumpServer 终端链路

前端入口：

- `TerminalWorkspace.tsx`
- `TerminalPane.tsx`
- `TerminalSplitView.tsx`
- `TerminalShortcuts.tsx`
- `TerminalAI.tsx`
- `useTerminalSession.ts`
- `useTerminalWindowManager.ts`

网关入口：

- `WS /ws/terminal`
- `WS /ws/jumpserver`

核心服务：

- `apps/gateway/src/modules/terminals/terminal-websocket.ts`
- `apps/gateway/src/modules/terminals/terminal-session-manager.ts`

主要风险：

- 终端滚动、光标跟随、复制粘贴浮层必须贴合 xterm viewport，而不是全页面定位
- detach/reattach 会引入 session 归属和 transcript 恢复问题
- Electron 窗口拖拽区不能覆盖终端按钮和工具栏按钮

业务能力：

- 远程内容与本地文件 Diff 对比
- SSH 隧道管理
- 多服务器批量命令执行

前端入口：

- `UtilityWorkspace.tsx`
- `DiffComparePanel.tsx`
- `SshTunnelPanel.tsx`
- `BatchCommandPanel.tsx`

网关入口：

- `POST /api/ssh/tunnel`
- `DELETE /api/ssh/tunnel/:tunnelId`
- `GET /api/ssh/tunnels`

核心服务：

- `apps/gateway/src/modules/logs/ssh-tunnel.service.ts`
- `apps/gateway/src/modules/logs/batch-command.service.ts`

主要风险：

- 这些是高危能力，入口要清晰，不应和日志阅读主路径抢空间
- 批量命令必须保留超时、输出隔离和失败可见性

### 3.8 录制与留痕

业务能力：

- 对当前日志文件启动远程录制
- 停止后生成输出文件
- 自动预览录制结果
- 记录到传输/操作历史中

前端入口：

- `SearchToolbarActions.tsx`
- `useLogRecording.ts`

网关入口：

- `POST /api/logs/recordings/start`
- `POST /api/logs/recordings/stop`

核心实现：

- `apps/gateway/src/index.ts` 中 recordings 路由
- `apps/gateway/src/modules/logs/file-transfer.service.ts`

主要风险：

- 录制是远程后台进程语义，停止失败时要清楚提示 pid 文件和输出路径
- 输出文件可能较大，预览和下载要走已有文件能力，不要单独拉全量

### 3.9 反馈、状态与本地持久化

业务能力：

- toast
- 文件 loading / 搜索进度
- 操作记录
- 传输记录
- 主题偏好
- workspace 状态缓存
- 目录历史和搜索条件恢复

前端入口：

- `FeedbackOverlays.tsx`
- `useToasts.ts`
- `useAsyncStatus.ts`
- `storage.ts`
- `useUiTheme.ts`
- `useWorkspaceSessionManager.ts`

主要风险：

- loading 和错误态不能过重，避免遮挡主工作流
- 持久化字段变化要考虑旧数据兼容
- 切 workspace 时不能把用户正在看的日志预览或文件目录误清掉

## 4. 共享协议

共享类型入口：

- `packages/shared/src/index.ts`

当前关键协议：

- `ServerSummary`
- `ServerRouteConfig`
- `JumpServerAsset*`
- `LogSearchRequest`
- `LogSearchResponse`
- `LogSearchTaskResponse`
- `MultiFileLogSearch*`
- `LogFile*`
- `LogSliceResponse`
- `LogLineContextResponse`
- `SshTunnel*`
- `BatchCommand*`

规则：

- 前后端新增字段优先进入 shared
- Electron IPC 专属字段不要放 shared
- 前端 UI 局部状态不要放 shared
- gateway 内部策略细节不要放 shared

## 5. 当前仍然高风险的业务链路

| 链路 | 风险点 | 排查入口 |
|---|---|---|
| workspace 切换 | serverId、副作用、缓存恢复、终端归属互相影响 | `useWorkspaceSessionManager.ts`、`App.tsx` |
| 日志预览/文件目录切换 | `results`、`resultTabs`、`activeLogView`、viewer scroll 状态漂移 | `useLogViewer.ts`、`VirtualLogViewer.tsx` |
| 大文件底部定位 | UI 百分比、slice offset、文件尾部语义混用 | `useLogViewer.ts`、`LogSliceService` |
| 终端体验 | xterm viewport、底部光标、浮层定位、detached session | `useTerminalSession.ts`、`TerminalWorkspace.tsx` |
| Electron 打包后点击失效 | app-region drag、构建缓存、静态资源版本 | `theme-modern.css`、`styles-sidebar-toolbar.css`、`main.cjs` |
| JumpServer 分支 | direct 与 bastion-target 契约不一致 | `ssh-executor.service.ts`、`strategies/*` |

## 6. 阅读代码建议

新排查任务优先按以下顺序读：

1. 先读本文件确认功能域
2. 再读 `docs/架构与修改地图.md` 确认模块落点
3. 样式问题读 `docs/style-architecture.md`
4. Electron 问题读 `docs/Electron-macOS-开发指南.md`
5. 历史问题只在需要查旧决策时读 `docs/archive/`
